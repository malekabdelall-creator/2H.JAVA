# JavaHomework

This Apache NetBeans Maven project contains six separate Java homework programs.

- `Homework1`: odd numbers from 1 to n
- `Homework2`: prime numbers from 1 to n
- `Homework3`: horizontal line of n stars
- `Homework4`: square of stars
- `Homework5`: triangle of stars
- `Homework6`: reverse triangle of stars

## Open in NetBeans
1. Extract this ZIP file.
2. In NetBeans, choose **File > Open Project**.
3. Select the extracted `JavaHomework` folder (the folder containing `pom.xml`).
4. Expand **Source Packages > homework**.
5. Right-click the homework file you want and choose **Run File** (or press Shift+F6).
